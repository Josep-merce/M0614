Context i teoria mínima

AWS (Amazon Web Services) és una plataforma de núvol que ofereix serveis sota demanda: servidors, emmagatzematge, bases de dades, xarxes, etc. Durant el mòdul desplegaràs els teus serveis al núvol fent servir AWS.

Què és AWS Academy?

AWS Academy és el programa educatiu d'Amazon per a centres de formació. Permet a l'alumnat accedir a serveis reals d'AWS mitjançant crèdits, sense necessitat de targeta de crèdit ni d'obrir un compte personal de pagament.

El Learner Lab

L'accés a la consola es fa a través d'un laboratori (Learner Lab). Quan l'inicies, AWS et dona un entorn temporal amb un pressupost limitat. Dins el laboratori trobaràs un botó per obrir la consola d'AWS ja autenticada.

Pas a pas guiat

2.1 · Acceptar la invitació a AWS Academy

  1. Obre el correu d'invitació que t'ha enviat el professorat (assumpte amb "AWS Academy").
  2. Fes clic a l'enllaç Get Started / Accept invitation.
  3. Crea el compte amb les teves dades i una contrasenya, o inicia sessió si ja en tens un.
  4. Accepta les condicions del programa per completar l'alta.
⚠️

Si l'enllaç de la invitació ha caducat, demana al professorat que te'n reenviï una de nova. Les invitacions tenen data de validesa.

2.2 · Entrar al curs i obrir els mòduls

  1. Un cop dins, ves a Canvas (la plataforma d'AWS Academy).
  2. Selecciona el curs AWS Academy Learner Lab al qual t'han matriculat.
  3. Al menú lateral, obre Modules i després Learner Lab.

2.3 · Iniciar el laboratori

  1. Dins el Learner Lab, fes clic a Start Lab.
  2. Espera que l'indicador del costat de AWS es posi verd (pot trigar uns segons).
  3. Fixa't en el comptador de crèdits restants que apareix a la part superior: és el teu pressupost.
💡

El cercle al costat de "AWS" indica l'estat del laboratori: vermell = aturat, groc = iniciant-se, verd = a punt. Quan acabis, fes End Lab per estalviar crèdits.

2.4 · Obrir la consola d'AWS

  1. Amb l'indicador en verd, fes clic a AWS (el text al costat del cercle).
  2. S'obrirà una pestanya nova amb la consola d'AWS ja autenticada. No cal posar usuari ni contrasenya.

2.5 · Orientar-te per la consola

Fes una exploració bàsica per familiaritzar-te:

  • Cercador de serveis: a la barra superior, escriu el nom d'un servei (per exemple, EC2 o S3) per accedir-hi.
  • Regió: a la part superior dreta es mostra la regió activa. A AWS Academy sol ser N. Virginia (us-east-1). Comprova-la, però no la canviïs tret que t'ho indiquin.
  • Menú de serveis: el botó de quadrícula (a dalt a l'esquerra) llista totes les categories de serveis.
⚠️

Treballa sempre a la mateixa regió durant tot el curs. Els recursos creats en una regió no es veuen en una altra.

2.6 · Estructurar el repositori amb branques

Recordem com es treballa amb branques: cada AEA té la seva. A la terminal de VS Code pots veure-les i moure't entre elles:

bash
git branch

➜ Mostra la llista de branques i, amb un asterisc, en quina et trobes ara.

bash
git switch aea0

➜ Entra (canvia) a la branca aea0 per treballar-hi.

2.7 · Escriure un README en Markdown

Markdown és el format estàndard per documentar repositoris. Obre el README.md a VS Code i amplia'l amb una secció que descrigui com s'organitza la feina del mòdul. Recorda la sintaxi bàsica:

README.md
# Títol de nivell 1
## Títol de nivell 2

Text normal amb **negreta** i *cursiva*.

- Element de llista
- Un altre element

1. Llista numerada
2. Segon pas

`codi en línia`  i enllaços: [text](https://exemple.com)

A VS Code pots veure com queda amb la previsualització: clic dret sobre el fitxer → Open Preview (o Ctrl + Shift + V).

💡

Un bon README explica què és el projecte, com s'organitza (les branques per AEA) i com es navega per la feina. És la primera cosa que es veu en obrir el repositori a GitHub. A la branca aea0, posa-hi un títol que indiqui que és de l'AEA0 (per exemple # M0614 · AEA0 — Preparació de l'entorn) per no confondre'l amb el README del main; el fitxer segueix anomenant-se README.md a totes les branques.

2.8 · Enllaçar (o incrustar) la captura al README

Per fer referència a la captura des del README.md hi ha dues sintaxis de Markdown molt semblants. La diferència és l'admiració ! del davant:

README.md
# Incrusta la imatge (es veu dins el README)
![Consola AWS amb el lab actiu](evidencies/aea0/a3/aws-lab-actiu.png)

# Enllaç clicable (porta a la imatge en fer-hi clic)
[Consola AWS amb el lab actiu](evidencies/aea0/a3/aws-lab-actiu.png)

El text entre [ ] és la descripció i el text entre ( ) és la ruta del fitxer.

⚠️

La ruta és relativa al README. Com que el README.md ja és a l'arrel del repositori m0614, la ruta comença per evidencies/… i no per M0614/evidencies/… (si hi poses M0614/, GitHub buscarà una carpeta inexistent i l'enllaç es trencarà).

💡

Anomena el fitxer sense espais ni majúscules: aws-lab-actiu.png, no AWS Lab Actiu.png. Si per força hi ha un espai, s'ha d'escriure com %20, però és molt millor canviar el nom. Comprova que l'enllaç funciona amb Ctrl + Shift + V.
