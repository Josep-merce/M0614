AEA1 — Implanta arquitectures web

Muntarem un primer servidor web pas a pas, sense donar per fet cap coneixement previ. Farem el mateix desplegament de tres maneres diferents, cada cop una mica més avançada: a Linux, amb Docker i al núvol amb AWS.

Branca aea1 Resultat d'aprenentatge RA1

En acabar l'AEA1 seràs capaç de:

  • Explicar què és l'arquitectura client-servidor i com es comuniquen un navegador i un servidor web.
  • Instal·lar i configurar un servidor web Apache directament sobre Linux.
  • Fer el mateix desplegament dins d'un contenidor Docker.
  • Publicar una pàgina web a AWS amb Amazon S3.
