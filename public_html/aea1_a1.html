Servidor web a Linux (localhost)

Instal·larem un servidor web (Apache) directament sobre Linux i el veurem funcionar per primera vegada al nostre propi navegador.

Branca aea1 RA RA1 CA 1.1 · 1.2 · 1.3 · 1.7 · 1.8
0

Objectius i prerequisits

En aquesta activitat aprendràs a:

  • Explicar amb les teves paraules què és un servidor web i què és un client.
  • Instal·lar el servidor web Apache en una màquina Linux.
  • Comprovar que el servei està actiu i arrencat.
  • Publicar una pàgina pròpia (index.html) i veure-la des del navegador.

Prerequisits

  • Haver completat l'AEA0 (entorn, Git/GitHub i Docker ja preparats).
  • Tenir accés a una màquina Linux amb Debian amb permisos d'administrador (sudo).

Branca de treball

Tota la feina d'aquesta AEA es fa a la branca aea1. Si és el primer cop que hi treballes, crea-la a partir de main:

bash
git switch -c aea1

➜ Crea la branca aea1 i hi entra alhora (l'opció -c vol dir "crea").

Si ja la tenies creada d'una altra sessió:

bash
git switch aea1

➜ Entra a la branca aea1 ja existent (sense -c).

💡

Un servidor web és, simplement, un programa que espera peticions (per exemple, "envia'm la pàgina principal") i respon enviant fitxers (HTML, imatges...). Apache és un dels servidors web més utilitzats del món.

1

Context i teoria mínima

Què passa quan obres una pàgina web?

Imagina que demanes un llibre a un bibliotecari: tu el demanes i ell te'l porta. A la web passa el mateix. El teu navegador (Chrome, Firefox...) fa de client: demana una pàgina. Una altra màquina fa de servidor: la busca i te l'envia. Aquesta conversa es fa amb un "idioma" anomenat HTTP.

com es comuniquen client i servidor
PaperQui ésQuè fa
ClientEl navegador (Chrome, Firefox...)Demana una pàgina web escrivint una adreça o IP.
ServidorLa màquina amb Apache instal·latRep la petició i envia el fitxer index.html.

Com viatja la petició: el protocol HTTP

Cada cop que demanes una pàgina, el servidor respon amb la pàgina i un codi de tres xifres que diu si tot ha anat bé. Segur que algun cop has vist un 404:

CodiVol dirExemple habitual
2xxTot correcte200 OK
3xxT'envio a un altre lloc301 mogut
4xxHas demanat una cosa que no existeix o no pots veure404 no trobat
5xxEl servidor ha tingut un problema500 error intern

De què està feta una pàgina web?

Una web senzilla està feta de tres tipus d'ingredients:

  • HTML — el contingut i l'estructura (títols, paràgrafs, imatges).
  • CSS — com es veu (colors, mides, tipus de lletra).
  • Imatges i altres arxius.

Quan aquests arxius no canvien mai, parlem d'una pàgina estàtica (com la que farem avui). Si la pàgina es fabrica al moment segons qui la demana (per exemple, mostrant el teu nom quan inicies sessió), és una pàgina dinàmica.

On es posa un servidor web?

El mateix servidor es pot posar en marxa de tres maneres. En aquesta AEA les provarem totes tres, sempre amb el mateix resultat final (la teva pàgina al navegador):

  1. Directament sobre una màquina Linux → això és el que farem avui (A1).
  2. Dins d'un contenidor Docker → A2.
  3. Al núvol, en un servei d'internet com AWS → A3.
💡

Apache és el programa servidor web que farem servir. N'hi ha d'altres (nginx, o Tomcat per a aplicacions Java, que veuràs a l'AEA3), però Apache és dels més utilitzats del món.

💡

Avui la mateixa màquina farà de client i de servidor alhora. Per això parlem de localhost, que vol dir "aquest mateix ordinador".

2

Pas a pas guiat

2.1 · Actualitza el sistema

bash
sudo apt update

➜ Actualitza la llista de paquets disponibles. sudo vol dir "fes-ho com a administrador" i apt és el programa que instal·la coses a Debian.

2.2 · Instal·la Apache

bash
sudo apt install apache2 -y

➜ Instal·la el servidor web Apache. L'opció -y respon "sí" automàticament a les preguntes de confirmació.

2.3 · Comprova que el servei està actiu

bash
sudo systemctl status apache2

➜ Mostra l'estat del servei Apache. Ha de sortir active (running) en verd. Prem la tecla q per sortir d'aquesta pantalla.

2.4 · Localitza la carpeta del lloc web

Apache serveix per defecte els fitxers que hi ha a /var/www/html:

bash
ls /var/www/html

➜ Llista el contingut d'aquesta carpeta. ls vol dir "list" (llistar). Ara mateix hi hauria d'haver un fitxer index.html per defecte d'Apache.

2.5 · Crea la teva pròpia pàgina

bash
sudo nano /var/www/html/index.html

➜ Obre el fitxer index.html amb l'editor de text nano. Cal sudo perquè aquesta carpeta és protegida.

Esborra el contingut que hi hagi i escriu-hi aquest codi, canviant el nom pel teu:

index.html
<!DOCTYPE html>
<html lang="ca">
<head>
  <meta charset="UTF-8">
  <title>El meu servidor web</title>
</head>
<body>
  <h1>Servidor web a Linux — AEA1</h1>
  <p>Nom Cognom</p>
</body>
</html>
💡

Per desar i sortir de nano: Ctrl+O (desa), Enter (confirma), Ctrl+X (surt).

2.6 · Comprova els permisos

Si el navegador dona un error de permisos, comprova que el fitxer sigui llegible:

bash
ls -l /var/www/html/index.html

➜ Mostra els permisos del fitxer. L'opció -l ("long") dona informació detallada: qui el pot llegir, escriure o executar.

3

Verificació

Obre el navegador dins de la mateixa màquina i visita:

navegador
http://localhost

➜ localhost vol dir "aquest mateix ordinador". Hauries de veure la pàgina amb el teu nom.

També ho pots comprovar per terminal:

bash
curl http://localhost

➜ curl demana la pàgina des de la terminal i te'n mostra el codi HTML, sense navegador.

💡

Si veus el teu missatge, tot ha anat bé. Si veus la pàgina per defecte d'Apache, encara no has sobreescrit index.html.
