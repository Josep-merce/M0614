S3 (Simple Storage Service) és un servei d'AWS pensat per emmagatzemar fitxers. No és un servidor tradicional com Apache, però pot servir fitxers HTML directament per internet.

1

Context i teoria mínima

A l'A1 i l'A2 vas instal·lar Apache: un programa que escolta peticions i respon amb fitxers. Amb S3 no instal·les cap programa: simplement puges els fitxers a un bucket i AWS els serveix, sense cap "màquina" que hagis de configurar.

ConcepteQuè és
BucketUna "carpeta" a S3. El nom ha de ser únic a tot AWS.
Allotjament de lloc web estàticOpció del bucket que fa que els HTML es vegin com una pàgina web.
Accés públicPermís que cal activar per a que qualsevol pugui veure els fitxers.
Endpoint del lloc webL'URL que AWS genera per accedir a la teva pàgina.
2

Pas a pas guiat

2.1 · Entra al Learner Lab i inicia'l

  1. Accedeix a AWS Academy amb el teu usuari de l'institut.
  2. Entra al Learner Lab i fes clic a Start Lab.
  3. Espera el punt verd i fes clic a AWS per obrir la consola.

2.2 · Crea el bucket

  1. Cerca el servei S3 i fes clic a Create bucket.
  2. Posa-li un nom únic, per exemple aea1-nomcognom-2026.
  3. Desmarca Block all public access i confirma.
  4. Fes clic a Create bucket.

2.3 · Activa l'allotjament de lloc web estàtic

  1. Entra al bucket i vés a Properties.
  2. Baixa fins a Static website hosting i fes clic a Edit.
  3. Activa Enable i escriu index.html a Index document.
  4. Desa i apunta l'adreça de Bucket website endpoint.

2.4 · Prepara el teu index.html

Pots reutilitzar el de l'A1 canviant el text:

index.html
<!DOCTYPE html>
<html lang="ca">
<head>
  <meta charset="UTF-8">
  <title>El meu lloc web a S3</title>
</head>
<body>
  <h1>Lloc web a AWS S3 — AEA1</h1>
  <p>Nom Cognom</p>
</body>
</html>

2.5 · Puja el fitxer al bucket

  1. A la pestanya Objects, fes clic a Upload.
  2. Add files → selecciona index.html → Upload.

2.6 · Fes públic el fitxer

  1. Vés a Permissions del bucket.
  2. A Bucket policy, fes clic a Edit i enganxa (canviant NOM-DEL-TEU-BUCKET):
bucket policy — JSON
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AccesPublicLectura",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::NOM-DEL-TEU-BUCKET/*"
    }
  ]
}

Desa amb Save changes.

3

Verificació

Obre el navegador i visita l'adreça de l'endpoint:

navegador
http://NOM-DEL-TEU-BUCKET.s3-website-us-east-1.amazonaws.com

➜ És l'adreça web que et dona S3 (l'endpoint que vas apuntar). Substitueix NOM-DEL-TEU-BUCKET pel nom real del teu bucket. Hauries de veure la teva pàgina.

⚠️

Quan acabis, torna al Learner Lab i fes clic a End Lab.
