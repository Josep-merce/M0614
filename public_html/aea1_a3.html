El mateix servidor a AWS, amb S3

Donarem d'alta el compte a AWS Academy, entrarem per primera vegada a la consola des d'un laboratori i, tot seguit, farem el mateix servidor de l'A1 i l'A2 al núvol amb Amazon S3, sense crear cap màquina virtual.

Objectius i prerequisits

En aquesta activitat aprendràs a:

  • Acceptar la invitació i fer l'alta a AWS Academy.
  • Accedir per primera vegada a la consola d'AWS a través d'un laboratori del Learner Lab.
  • Orientar-te per la consola: regió, cercador de serveis i pressupost de crèdits.
  • Entrar al AWS Learner Lab i crear un bucket S3.
  • Activar l'allotjament de lloc web estàtic d'aquest bucket.
  • Pujar-hi el teu fitxer index.html i fer-lo públic.

Prerequisits

  • Haver completat l'A1 (reutilitzaràs el mateix index.html).
  • Tenir el correu d'invitació a AWS Academy enviat pel professorat.
  • Navegador web i connexió a Internet.

Serveis AWS implicats

Primer accedirem només a la consola d'AWS mitjançant el Learner Lab per familiaritzar-nos amb l'entorn; després crearem el nostre primer recurs (un bucket S3).

⚠️

AWS Academy es fa servir sense targeta de crèdit: treballaràs amb crèdits assignats. Vés amb compte d'aturar els recursos quan acabis per no esgotar-los.

💡

S3 (Simple Storage Service) és un servei d'AWS pensat per emmagatzemar fitxers. No és un servidor tradicional com Apache, però pot servir fitxers HTML directament per internet.

1

Context i teoria mínima

AWS (Amazon Web Services) és una plataforma de núvol que ofereix serveis sota demanda: servidors, emmagatzematge, bases de dades, xarxes, etc. Durant el mòdul desplegaràs els teus serveis al núvol fent servir AWS.

Què és AWS Academy?

AWS Academy és el programa educatiu d'Amazon per a centres de formació. Permet a l'alumnat accedir a serveis reals d'AWS mitjançant crèdits, sense necessitat de targeta de crèdit ni d'obrir un compte personal de pagament.

El Learner Lab

L'accés a la consola es fa a través d'un laboratori (Learner Lab). Quan l'inicies, AWS et dona un entorn temporal amb un pressupost limitat. Dins el laboratori trobaràs un botó per obrir la consola d'AWS ja autenticada.

A l'A1 i l'A2 vas instal·lar Apache: un programa que escolta peticions i respon amb fitxers. Amb S3 no instal·les cap programa: simplement puges els fitxers a un bucket i AWS els serveix, sense cap "màquina" que hagis de configurar.

Pas a pas guiat

2.1 · Acceptar la invitació a AWS Academy

  1. Obre el correu d'invitació que t'ha enviat el professorat (assumpte amb "AWS Academy").
  2. Fes clic a l'enllaç Get Started / Accept invitation.
  3. Crea el compte amb les teves dades i una contrasenya, o inicia sessió si ja en tens un.
  4. Accepta les condicions del programa per completar l'alta.
⚠️

Si l'enllaç de la invitació ha caducat, demana al professorat que te'n reenviï una de nova. Les invitacions tenen data de validesa.

2.2 · Entrar al curs i obrir els mòduls

  1. Un cop dins, ves a Canvas (la plataforma d'AWS Academy).
  2. Selecciona el curs AWS Academy Learner Lab al qual t'han matriculat.
  3. Al menú lateral, obre Modules i després Learner Lab.

2.3 · Iniciar el laboratori

  1. Dins el Learner Lab, fes clic a Start Lab.
  2. Espera que l'indicador del costat de AWS es posi verd (pot trigar uns segons).
  3. Fixa't en el comptador de crèdits restants que apareix a la part superior: és el teu pressupost.
💡

El cercle al costat de "AWS" indica l'estat del laboratori: vermell = aturat, groc = iniciant-se, verd = a punt. Quan acabis, fes End Lab per estalviar crèdits.

2.4 · Obrir la consola d'AWS

  1. Amb l'indicador en verd, fes clic a AWS (el text al costat del cercle).
  2. S'obrirà una pestanya nova amb la consola d'AWS ja autenticada. No cal posar usuari ni contrasenya.

2.5 · Orientar-te per la consola

Fes una exploració bàsica per familiaritzar-te:

  • Cercador de serveis: a la barra superior, escriu el nom d'un servei (per exemple, EC2 o S3) per accedir-hi.
  • Regió: a la part superior dreta es mostra la regió activa. A AWS Academy sol ser N. Virginia (us-east-1). Comprova-la, però no la canviïs tret que t'ho indiquin.
  • Menú de serveis: el botó de quadrícula (a dalt a l'esquerra) llista totes les categories de serveis.
⚠️

Treballa sempre a la mateixa regió durant tot el curs. Els recursos creats en una regió no es veuen en una altra.

2.6 · Crea el bucket

  1. Cerca el servei S3 i fes clic a Create bucket.
  2. Posa-li un nom únic, per exemple aea1-nomcognom-2026.
  3. Desmarca Block all public access i confirma.
  4. Fes clic a Create bucket.

2.7 · Activa l'allotjament de lloc web estàtic

  1. Entra al bucket i vés a Properties.
  2. Baixa fins a Static website hosting i fes clic a Edit.
  3. Activa Enable i escriu index.html a Index document.
  4. Desa i apunta l'adreça de Bucket website endpoint.

2.8 · Prepara el teu index.html

Pots reutilitzar el de l'A1 canviant el text:

index.html
<!DOCTYPE html>
<html lang="ca">
<head>
  <meta charset="UTF-8">
  <title>El meu lloc web a S3</title>
</head>
<body>
  <h1>Lloc web a AWS S3 — AEA1</h1>
  <p>Nom Cognom</p>
</body>
</html>

2.9 · Puja el fitxer al bucket

  1. A la pestanya Objects, fes clic a Upload.
  2. Add files → selecciona index.html → Upload.

2.10 · Fes públic el fitxer

  1. Vés a Permissions del bucket.
  2. A Bucket policy, fes clic a Edit i enganxa (canviant NOM-DEL-TEU-BUCKET):
bucket policy — JSON
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AccesPublicLectura",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::NOM-DEL-TEU-BUCKET/*"
    }
  ]
}

Desa amb Save changes.

Verificació

  • Pots iniciar sessió a AWS Academy i veure el curs Learner Lab.
  • En fer Start Lab, l'indicador d'AWS es posa verd i veus els crèdits restants.
  • El botó AWS obre la consola sense demanar credencials.

Obre el navegador i visita l'adreça de l'endpoint:

navegador
http://NOM-DEL-TEU-BUCKET.s3-website-us-east-1.amazonaws.com

➜ És l'adreça web que et dona S3 (l'endpoint que vas apuntar). Substitueix NOM-DEL-TEU-BUCKET pel nom real del teu bucket. Hauries de veure la teva pàgina.

⚠️

Quan acabis, torna al Learner Lab i fes clic a End Lab.
