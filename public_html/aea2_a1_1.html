Munta un servidor web amb el teu lloc i una zona privada

Sobre la xarxa de l'A0, instal·laràs Apache al servidor per SSH i hi publicaràs el teu propi lloc web: una pàgina d'inici, una pàgina sobre tu i un full d'estils comú, amb un menú que les uneix. El client hi accedirà pel nom (www.aea2.local). Quan tot funcioni, afegiràs una zona privada que només s'obre amb usuari i contrasenya.

RA RA2 CA 2.3 · 2.4 · 2.8
0

Objectius i prerequisits

En aquesta activitat aprendràs a:

  • Instal·lar Apache al servidor treballant per SSH des de l'administrador.
  • Crear el teu propi lloc web amb dues pàgines (index.html i sobre-mi.html) i un full d'estils comú (style.css).
  • Configurar un host virtual perquè Apache serveixi aquest lloc.
  • Fer que el client hi accedeixi pel nom (www.aea2.local) editant /etc/hosts.
  • Protegir només una part del lloc (la carpeta privat) amb usuari i contrasenya.

Prerequisit important

⚠️

Aquesta activitat continua l'A0. Has de tenir les tres màquines amb IP fixa a la xarxa interna i poder entrar al servidor per SSH des de l'administrador. Si no ho tens, fes primer l'A0.

1

Context i teoria mínima

A l'A0 vas muntar la xarxa de tres màquines i l'accés per SSH. Ara instal·laràs Apache al servidor i hi publicaràs el teu lloc. Per fer-ho fem servir aquestes eines d'Apache i del sistema:

ConcepteQuè és
HTTPProtocol per transportar pàgines web. Port 80.
Host virtualConfiguració que li diu a Apache quin nom té un lloc i en quina carpeta són els seus fitxers (DocumentRoot). Permet tenir diversos llocs al mateix servidor.
DocumentRootLa carpeta on hi ha els fitxers del lloc (aquí /var/www/aea2).
Resolució de nomsTraduir un nom (www.aea2.local) a una IP. Per a proves ho fem al fitxer /etc/hosts del client.
Full d'estils (CSS)Fitxer style.css amb els colors i el menú. Totes les pàgines l'enllacen, així només el canvies en un lloc.
Autenticació bàsicaDemana usuari i contrasenya per entrar en una carpeta. La contrasenya es desa xifrada amb htpasswd. No xifra el trànsit: la contrasenya viatja per la xarxa sense xifrar.

Així quedarà el teu lloc quan acabis. Fixa't que només la carpeta privat està protegida:

estructura del lloc
/var/www/aea2/            # DocumentRoot: el teu lloc
├── index.html            # Inici        → públic
├── sobre-mi.html         # Sobre mi     → públic
├── style.css             # estil de totes les pàgines
└── privat/
    └── index.html        # Zona privada → demana usuari i contrasenya
💡

El nom acaba en .local perquè és un nom de proves intern; no és un domini real d'Internet. La "traducció" nom → IP la fem manualment a /etc/hosts.

2

Pas a pas guiat

💡

Cada pas ve dins d'una capsa de color que indica qui l'ha de fer: AdministradorServidorClient. Els fitxers de configuració no porten capsa.

Part 1 · Instal·la Apache

2.1 · Connecta't al servidor per SSH

Administrador

Des de la màquina administrador, obre una sessió SSH al servidor com vas fer a l'A0, amb l'usuari isard_ssh:

bash — administrador
ssh isard_ssh@192.168.1.10

➜ Obre una sessió de terminal xifrada al servidor per SSH.

💻→

A partir d'aquí, tot el que escrius s'executa al servidor, no a l'administrador. Per tornar a l'administrador quan acabis, escriu exit.

2.2 · Instal·la Apache

Administrador → Servidor · per SSH

Ja connectat per SSH al servidor, actualitza la llista de paquets i instal·la Apache:

bash — administrador → servidor (SSH)
sudo apt update

➜ Actualitza la llista de paquets disponibles. Convé fer-ho abans d'instal·lar res.

bash — administrador → servidor (SSH)
sudo apt install apache2 -y

➜ Instal·la el servidor web Apache. -y accepta automàticament la instal·lació.

🔎 Comprova-ho al navegador del client http://192.168.1.10

Ha de sortir la pàgina per defecte d'Apache (Apache2 Debian Default Page). El servidor web ja funciona.

💡

Recarrega sempre la pàgina amb Ctrl+F5 per veure els canvis. Deixa aquesta pestanya oberta: la faràs servir a cada pas.

Part 2 · El teu lloc web públic

Treballa amb dues finestres obertes: el terminal de l'administrador connectat per SSH al servidor (on fas els canvis) i el navegador del client (on els comproves). Cada cop que un canvi es pot veure, trobaràs un requadre blau 🔎 Comprova-ho al navegador del client.

2.3 · Crea la carpeta del lloc i una pàgina de prova

Administrador → Servidor · per SSH
bash — administrador → servidor (SSH)
sudo mkdir /var/www/aea2

➜ Crea la carpeta on hi haurà els fitxers del teu lloc web.

Crea una pàgina de prova per comprovar que el lloc funciona (més endavant la canviaràs per la de debò):

bash — administrador → servidor (SSH)
echo "<h1>Funciona! · AEA2</h1>" | sudo tee /var/www/aea2/index.html

➜ Escriu una pàgina d'inici provisional. La canonada | sudo tee desa el text al fitxer amb permisos d'administrador.

2.4 · Crea i activa el host virtual

Administrador → Servidor · per SSH

Crea el fitxer de configuració del teu lloc:

bash — administrador → servidor (SSH)
sudo nano /etc/apache2/sites-available/aea2.conf

➜ Obre amb nano el fitxer on definirem el nostre lloc (host virtual).

Escriu-hi aquest contingut:

aea2.conf
<VirtualHost *:80>
    ServerName www.aea2.local
    DocumentRoot /var/www/aea2
</VirtualHost>

➜ Explicació de cada línia:

  • <VirtualHost *:80> → obre la definició d'un lloc web que escolta al port 80 (HTTP).
  • ServerName www.aea2.local → el nom pel qual s'accedirà al lloc.
  • DocumentRoot /var/www/aea2 → la carpeta on hi ha els fitxers del lloc.
  • </VirtualHost> → tanca la definició del lloc.

Desa (Ctrl+O, Enter) i surt (Ctrl+X).

bash — administrador → servidor (SSH)
sudo a2ensite aea2

➜ Activa el lloc aea2 a Apache (l'afegeix a sites-enabled).

bash — administrador → servidor (SSH)
sudo systemctl reload apache2

➜ Recarrega Apache perquè apliqui la nova configuració sense aturar el servei.

2.5 · Fes que el client accedeixi pel nom

Client

Ves a la màquina client i edita el fitxer /etc/hosts:

bash — client
sudo nano /etc/hosts

➜ Obre al client el fitxer que associa noms a adreces IP.

Afegeix aquesta línia al final:

/etc/hosts — client
192.168.1.10   www.aea2.local

➜ Associa el nom www.aea2.local a la IP del servidor, de manera que el client hi arribi pel nom.

Desa (Ctrl+O, Enter) i surt (Ctrl+X).

🔎 Comprova-ho al navegador del client http://www.aea2.local

Ha de sortir el títol Funciona! · AEA2. Ja tens el teu propi lloc publicat amb un nom.

2.6 · Crea el full d'estils

Administrador → Servidor · per SSH
bash — administrador → servidor (SSH)
sudo nano /var/www/aea2/style.css

➜ Crea el fitxer d'estils que faran servir totes les pàgines del lloc.

Escriu-hi aquest contingut:

style.css
/* ---- Estil general ---- */
body {
    font-family: Arial, sans-serif;
    margin: 0;
    padding-top: 70px;
    text-align: center;
    background: #f1f5f9;
    color: #1e293b;
}

/* ---- Menú ---- */
nav {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    background: #0f172a;
    padding: 15px;
}
nav a {
    color: white;
    text-decoration: none;
    font-weight: bold;
    margin: 0 15px;
}
nav a:hover {
    color: #ffd166;
}

➜ La primera part dona color i lletra a tota la pàgina. La part nav és el menú: una barra fosca fixa a dalt de tot amb enllaços blancs que es tornen grocs (:hover) quan hi passes el ratolí. El padding-top del body evita que el menú tapi el contingut.

Desa (Ctrl+O, Enter) i surt (Ctrl+X).

Encara no es veu res: el menú apareixerà quan l'enllacis des de la pàgina d'inici.

2.7 · Crea la pàgina d'inici amb el menú

Administrador → Servidor · per SSH
bash — administrador → servidor (SSH)
sudo nano /var/www/aea2/index.html

➜ Obre la pàgina d'inici provisional del pas 2.3.

Esborra la línia que hi ha (Ctrl+K) i escriu-hi aquest contingut:

index.html
<!DOCTYPE html>
<html lang="ca">
<head>
    <meta charset="UTF-8">
    <title>Inici</title>
    <link rel="stylesheet" href="/style.css">
</head>
<body>
    <nav>
        <a href="/index.html">Inici</a>
        <a href="/sobre-mi.html">Sobre mi</a>
        <a href="/privat/">Zona privada</a>
    </nav>
    <h1>El meu servidor segur · AEA2</h1>
    <p>Benvingut al meu lloc web.</p>
</body>
</html>

➜ La línia <link rel="stylesheet" href="/style.css"> enllaça el full d'estils. El bloc <nav> és el menú, amb un enllaç <a href> a cada pàgina del lloc.

Desa (Ctrl+O, Enter) i surt (Ctrl+X).

🔎 Comprova-ho al navegador del client http://www.aea2.local

A dalt de tot ha de sortir una barra fosca amb els enllaços Inici · Sobre mi · Zona privada. Passa-hi el ratolí: es tornen grocs. (Sobre mi i Zona privada encara donen error 404: les farem als passos següents.)

2.8 · Crea la pàgina sobre tu

Administrador → Servidor · per SSH
bash — administrador → servidor (SSH)
sudo nano /var/www/aea2/sobre-mi.html

➜ Crea la segona pàgina del lloc.

Escriu-hi aquest contingut i canvia el text per les teves dades:

sobre-mi.html
<!DOCTYPE html>
<html lang="ca">
<head>
    <meta charset="UTF-8">
    <title>Sobre mi</title>
    <link rel="stylesheet" href="/style.css">
</head>
<body>
    <nav>
        <a href="/index.html">Inici</a>
        <a href="/sobre-mi.html">Sobre mi</a>
        <a href="/privat/">Zona privada</a>
    </nav>
    <h1>Sobre mi</h1>
    <p>Em dic Nom Cognom i estudio DAW a l'Institut La Mercè.</p>
    <p>M'agrada...</p>
</body>
</html>

➜ Té el mateix <head> i el mateix <nav> que l'inici: així totes dues pàgines tenen el mateix estil i el mateix menú.

Desa (Ctrl+O, Enter) i surt (Ctrl+X).

🔎 Comprova-ho al navegador del client http://www.aea2.local/sobre-mi.html

Ha de sortir la teva pàgina amb el menú. Clica Inici i Sobre mi i comprova que et porten al lloc correcte. (Zona privada encara dona error 404.)

Part 3 · La zona privada

2.9 · Crea la carpeta i la pàgina privada

Administrador → Servidor · per SSH
bash — administrador → servidor (SSH)
sudo mkdir /var/www/aea2/privat

➜ Crea la carpeta privat dins del teu lloc. És la que protegirem amb contrasenya.

bash — administrador → servidor (SSH)
sudo nano /var/www/aea2/privat/index.html

➜ Crea la pàgina que es veurà quan entris a la zona privada.

Escriu-hi aquest contingut:

privat/index.html
<!DOCTYPE html>
<html lang="ca">
<head>
    <meta charset="UTF-8">
    <title>Zona privada</title>
    <link rel="stylesheet" href="/style.css">
</head>
<body>
    <nav>
        <a href="/index.html">Inici</a>
        <a href="/sobre-mi.html">Sobre mi</a>
        <a href="/privat/">Zona privada</a>
    </nav>
    <h1>Zona privada</h1>
    <p>Només hi pot entrar qui sap l'usuari i la contrasenya.</p>
</body>
</html>

Desa (Ctrl+O, Enter) i surt (Ctrl+X).

🔎 Comprova-ho al navegador del client http://www.aea2.local/privat/

Clica Zona privada al menú. La pàgina s'obre sense demanar contrasenya: de moment qualsevol hi pot entrar. Al pas següent ho arreglem.

2.10 · Protegeix la carpeta amb usuari i contrasenya

Administrador → Servidor · per SSH

Crea un usuari (aquí laura); et demanarà la contrasenya dues vegades (no es veu mentre l'escrius):

bash — administrador → servidor (SSH)
sudo htpasswd -c /etc/apache2/.htpasswd laura

➜ Crea l'usuari laura i desa la seva contrasenya xifrada. -c crea el fitxer de contrasenyes (només s'usa el primer cop; després no).

Torna a obrir aea2.conf per afegir-hi el bloc <Directory> dins del <VirtualHost>:

bash — administrador → servidor (SSH)
sudo nano /etc/apache2/sites-available/aea2.conf

➜ Torna a obrir el fitxer del host virtual per afegir-hi la protecció amb contrasenya.

aea2.conf
<VirtualHost *:80>
    ServerName www.aea2.local
    DocumentRoot /var/www/aea2

    <Directory /var/www/aea2/privat>
        AuthType Basic
        AuthName "Zona privada"
        AuthUserFile /etc/apache2/.htpasswd
        Require valid-user
    </Directory>
</VirtualHost>

➜ Explicació de les línies noves (les del bloc <Directory>):

  • <Directory /var/www/aea2/privat> → comença un bloc de regles només per a la carpeta privat. La resta del lloc continua sent pública.
  • AuthType Basic → tipus d'autenticació: usuari i contrasenya.
  • AuthName "Zona privada" → text que apareix a la finestra que demana les credencials.
  • AuthUserFile /etc/apache2/.htpasswd → fitxer on són desades les contrasenyes (el que has creat amb htpasswd).
  • Require valid-user → pot entrar qualsevol usuari del fitxer .htpasswd (de moment només hi ha laura). Si després crees més usuaris amb htpasswd, també podran entrar sense tocar la configuració.
  • </Directory> → tanca el bloc de regles de la carpeta.

Desa (Ctrl+O, Enter) i surt (Ctrl+X).

bash — administrador → servidor (SSH)
sudo systemctl reload apache2

➜ Recarrega Apache perquè la carpeta quedi protegida.

🔎 Comprova-ho al navegador del client http://www.aea2.local/privat/

Obre una finestra d'incògnit (Ctrl+Shift+N) perquè el navegador no recordi res. Inici i Sobre mi s'obren igual que abans; Zona privada ara demana usuari i contrasenya. Escriu laura i la contrasenya: ha de sortir la pàgina privada.

3

Verificació

  • Al client, http://www.aea2.local mostra el teu lloc amb el menú, i Inici i Sobre mi s'obren sense contrasenya.
  • http://www.aea2.local/privat/ demana usuari i contrasenya i, en encertar-los, mostra la zona privada.
Client

Des del client, comprova les tres situacions amb curl. Primer, la part pública:

bash — client
curl http://www.aea2.local

➜ Demana la pàgina d'inici. Ha de retornar el codi HTML de l'inici, sense demanar res.

Després, la zona privada sense identificar-te:

bash — client
curl http://www.aea2.local/privat/

➜ Ha de respondre amb un error 401 Unauthorized. Si en canvi retorna el HTML de la zona privada, la carpeta no està protegida (revisa el pas 2.10).

Finalment, la zona privada identificant-te (l'opció -u envia l'usuari):

bash — client
curl -u laura http://www.aea2.local/privat/

➜ Demana la zona privada identificant-se com laura (et demanarà la contrasenya).

Sortida esperada: primer et demana la contrasenya i, si l'encertes, el codi HTML de la pàgina privada:

sortida esperada
Enter host password for user 'laura':   # escriu la contrasenya i prem Enter
<!DOCTYPE html>
...
    <h1>Zona privada</h1>
...
💡

Fem la verificació des del client perquè és la màquina que té www.aea2.local al seu /etc/hosts. Si la contrasenya és incorrecta, curl respon 401 Unauthorized en lloc del HTML.

Errors freqüents

ProblemaCausaSolució
http://192.168.1.10 no carrega al clientApache no està instal·lat o no hi ha connexió amb el servidor.Comprova systemctl status apache2 al servidor i fes ping 192.168.1.10 des del client.
www.aea2.local no s'obre al clientFalta la línia a /etc/hosts del client, o té una IP incorrecta.Afegeix 192.168.1.10 www.aea2.local a /etc/hosts del client.
Es mostra la pàgina d'Apache i no la mevaEl lloc no està activat, el DocumentRoot no apunta a /var/www/aea2 o has escrit la IP en lloc del nom per HTTP.Comprova sudo a2ensite aea2 i el DocumentRoot. Per HTTP fes servir http://www.aea2.local: amb la IP, Apache mostra el lloc per defecte.
No veig els canvisNo has desat el fitxer o el navegador mostra la versió antiga.Desa amb Ctrl+O i recarrega amb Ctrl+F5.
El menú no surt, o surt sense colorsLa pàgina no enllaça el CSS, o style.css no és a /var/www/aea2.Comprova la línia <link rel="stylesheet" href="/style.css"> i fes ls /var/www/aea2.
Un enllaç del menú dona error 404El nom del fitxer no coincideix amb l'enllaç (per exemple sobremi.html en lloc de sobre-mi.html).Mira els noms reals amb ls /var/www/aea2 i corregeix l'enllaç o el fitxer perquè siguin iguals.
L'inici també demana contrasenyaEl bloc <Directory> apunta a /var/www/aea2 (tot el lloc) en lloc de /var/www/aea2/privat.Corregeix la ruta del <Directory> i recarrega Apache.

curl: no s'ha trobat l'ordre al clientEl client no té curl instal·lat.Instal·la'l amb sudo apt install curl -y.
Contrasenya sempre incorrectaL'usuari no s'ha creat bé o el fitxer no és el mateix de la config.Torna a crear-lo amb sudo htpasswd /etc/apache2/.htpasswd laura (sense -c per no esborrar-lo) i comprova AuthUserFile.
