El mateix servidor segur amb Docker

Ara muntaràs el mateix servidor web amb HTTPS, però dins d'un contenidor Docker a partir de la imatge oficial d'Apache. Aquí només tenim el servidor: tot passa en una sola màquina, sense la xarxa de tres equips.

Branca aea2 RA RA2 CA 2.5 · 2.6 · 2.9
0

Objectius i prerequisits

En aquesta activitat aprendràs a:

  • Fer servir la imatge oficial d'Apache (httpd) de Docker.
  • Construir una imatge pròpia amb HTTPS activat i el teu certificat.
  • Executar el servidor en un contenidor i publicar-lo a un port de la teva màquina.

Prerequisits

  • Docker instal·lat i funcionant (AEA0).
  • Saber la diferència entre imatge i contenidor (AEA0).
  • El teu repositori m0614 amb la branca aea2.

Branca de treball

Continuem a la mateixa branca de l'AEA. Situa-t'hi:

bash
git switch aea2
💡

Aquí no fem la xarxa de tres màquines. Docker ens permet tenir el servidor aïllat en un contenidor a la nostra pròpia màquina, i el provem des del navegador local.

1

Context i teoria mínima

A l'A1 vas instal·lar Apache "a mà" en una màquina. Amb Docker aconseguim el mateix servidor, però empaquetat en una imatge: una plantilla que ja porta Apache i la nostra configuració. Cada cop que l'executem, en surt un contenidor idèntic, sense haver de reinstal·lar res.

ConcepteQuè és
Imatge oficial httpdLa imatge d'Apache mantinguda a Docker Hub. La fem servir de base.
DockerfileUn fitxer de text amb les instruccions per construir la nostra imatge a partir de la base.
Construir (build)Crear la nostra imatge a partir del Dockerfile.
Mapatge de ports (-p)Connectar un port de la nostra màquina amb el del contenidor. Ex.: 8443:443.
💡

Publicarem el 443 del contenidor al 8443 de la màquina per no xocar amb altres serveis. Hi accedirem amb https://localhost:8443.

2

Pas a pas guiat

2.1 · Comprovar que Docker funciona

bash
docker --version

➜ Mostra la versió de Docker instal·lada; així comproves que funciona.

2.2 · Crear l'estructura de carpetes

Crea una carpeta per a aquesta activitat amb dues subcarpetes (una per a la web, una per als certificats):

bash
mkdir -p aea2-docker/web aea2-docker/certs

➜ Crea la carpeta del projecte amb dues subcarpetes. -p crea també les carpetes pare si no existeixen.

bash
cd aea2-docker

➜ Entra dins la carpeta del projecte. cd vol dir "canvia de directori".

Quan acabis aquesta activitat, la carpeta quedarà així (cada fitxer el crees als passos següents):

estructura de aea2-docker/
aea2-docker/            # carpeta del projecte
├── Dockerfile          # instruccions de la imatge (pas 2.4)
├── certs/              # certificats
│   ├── aea2.crt        # certificat (pas 2.3)
│   └── aea2.key        # clau privada (pas 2.3)
└── web/                # fitxers del lloc web
    └── index.html      # la teva pàgina (a continuació)

Ara mateix només existeixen les carpetes certs/ i web/; els fitxers els aniràs creant tot seguit.

Crea una pàgina web senzilla dins web/:

web/index.html
<!DOCTYPE html>
<html lang="ca">
<body>
  <h1>Servidor segur amb Docker · AEA2</h1>
  <p>Aquesta pàgina se serveix per HTTPS des d'un contenidor.</p>
</body>
</html>

2.3 · Generar el certificat autofirmat

Genera el certificat dins certs/ (a Common Name pots posar localhost):

bash
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout certs/aea2.key \
  -out certs/aea2.crt

➜ Genera el certificat i la clau dins certs/. És una sola ordre (les barres \ uneixen les línies): -x509 crea un certificat autofirmat, -nodes no posa contrasenya a la clau i -days 365 el fa vàlid un any.

En executar-la, l'openssl et farà unes quantes preguntes (el subject del certificat). Pots respondre-les així:

preguntes del certificat
Country Name (2 letter code):    # país, 2 lletres → ES
State or Province Name:          # província → Barcelona
Locality Name (eg, city):        # ciutat → Barcelona
Organization Name:               # organització → Institut La Merce
Organizational Unit Name:        # departament (opcional) → DAW
Common Name:                     # ⚠ EL MÉS IMPORTANT: l'adreça del servidor → localhost
Email Address:                   # correu (opcional) → pots deixar-ho buit
💡

El camp que de debò importa és el Common Name (CN): ha de coincidir amb l'adreça per la qual accediràs al servidor (aquí localhost). La resta de camps són informatius i els pots deixar buits prement Enter.

2.4 · Escriure el Dockerfile

A l'arrel de aea2-docker/, crea un fitxer anomenat Dockerfile (sense extensió):

Dockerfile
# Partim de la imatge oficial d'Apache
FROM httpd:2.4

# Activem els mòduls d'SSL i la configuració HTTPS d'Apache
RUN sed -i \
  -e 's/^#\(LoadModule ssl_module .*\)/\1/' \
  -e 's/^#\(LoadModule socache_shmcb_module .*\)/\1/' \
  -e 's/^#\(Include .*httpd-ssl.conf\)/\1/' \
  conf/httpd.conf

# Copiem el nostre certificat (Apache els busca amb aquests noms)
COPY certs/aea2.crt /usr/local/apache2/conf/server.crt
COPY certs/aea2.key /usr/local/apache2/conf/server.key

# Copiem la nostra pàgina web
COPY web/ /usr/local/apache2/htdocs/
💡

Cada línia és una instrucció: FROM tria la base, RUN executa ordres en construir la imatge, i COPY hi posa els nostres fitxers a dins.

2.5 · Construir la imatge

Des de dins de aea2-docker/ (on hi ha el Dockerfile):

bash
docker build -t aea2-web .

➜ Construeix la imatge a partir del Dockerfile. -t aea2-web li posa nom i el punt final indica que el Dockerfile és a la carpeta actual.

2.6 · Executar el contenidor

bash
docker run -d --name servidor-aea2 -p 8443:443 aea2-web

➜ Crea i engega el contenidor. -d l'executa en segon pla, --name servidor-aea2 li posa nom i -p 8443:443 publica el port HTTPS del contenidor al 8443 de la teva màquina.

2.7 · Accedir al web

Obre el navegador de la teva màquina i ves a:

navegador
https://localhost:8443

Accepta l'avís del certificat autofirmat i veuràs la teva pàgina servida per HTTPS des del contenidor.

Verificació

bash
docker ps
curl -k https://localhost:8443

NAMES
servidor-aea2

Sortida esperada de curl -k https://localhost:8443 (el codi HTML de la teva pàgina; el contingut exacte depèn del que hagis posat a web/index.html):

sortida esperada
<h1>Servidor segur amb Docker · AEA2</h1>
<p>Aquesta pàgina se serveix per HTTPS des d'un contenidor.</p>
💡

L'opció -k fa que curl accepti el certificat autofirmat sense donar l'error SSL certificate problem. Si l'ordre respon amb HTML (sense error de connexió), la verificació és correcta.

  • docker ps mostra el contenidor servidor-aea2 en estat Up amb el mapatge 8443->443.
  • curl -k retorna el codi HTML de la teva pàgina.
  • El navegador mostra la pàgina per https://localhost:8443.
