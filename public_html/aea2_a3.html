Servidor segur a una EC2 per SSH

Ara portaràs el mateix servidor al núvol. Llançaràs una màquina virtual (EC2) a AWS Academy, t'hi connectaràs de manera segura per SSH amb una clau i hi publicaràs el web amb HTTPS, accessible des de la seva IP pública.

Branca aea2 RA RA2 CA 2.5 · 2.6 · 2.9

Objectius i prerequisits

En aquesta activitat aprendràs a:

  • Llançar una instància EC2 al Learner Lab d'AWS Academy.
  • Obrir només els ports necessaris amb un security group (22, 80 i 443).
  • Connectar-t'hi de manera segura per SSH amb una clau .pem.
  • Instal·lar Apache i publicar el web amb HTTPS a la IP pública.

  • Accés a AWS Academy · Learner Lab (AEA0).
  • Un terminal a la teva màquina per fer ssh.
  • El teu repositori m0614 amb la branca aea2.

1

Context i teoria mínima

Fins ara el servidor era a l'aula (A1) o en un contenidor local (A2). Ara serà una màquina real al núvol d'AWS: una EC2. Com que és pública, l'administrarem igualment per SSH, però la seguretat de la connexió ve d'una clau (fitxer .pem) en lloc d'una contrasenya.

ConcepteQuè és
EC2Una màquina virtual llogada a AWS.
AMILa imatge del sistema operatiu amb què s'engega l'EC2 (farem servir Ubuntu).
Key pair (.pem)La clau privada per connectar-te per SSH. Substitueix la contrasenya.
Security groupEl tallafoc de l'EC2: decideix quins ports són accessibles des de fora.
IP públicaL'adreça per accedir a l'EC2 des d'Internet.

Pas a pas guiat

2.1 · Entrar al Learner Lab i obrir la consola

  1. Entra a AWS Academy i obre el teu Learner Lab.
  2. Prem Start Lab i espera que el punt del costat d'AWS es posi verd.
  3. Fes clic a AWS per obrir la consola d'AWS.

2.2 · Llançar la instància EC2

  1. A la consola, cerca EC2 i entra-hi. Prem Launch instance.
  2. Posa-li de nom servidor-aea2.
  3. A Application and OS Images, tria Ubuntu (Free tier).
  4. A Instance type, deixa t2.micro (Free tier).
  5. A Key pair, prem Create new key pair, posa-li nom aea2-key, format .pem, i descarrega-la. Guarda-la bé: només es descarrega un cop.

2.3 · Configurar el security group (ports)

A l'apartat Network settings de la mateixa pantalla de llançament, marca que s'obrin aquests ports:

PortServeiPer a què
22SSHAdministrar l'EC2 des del teu terminal.
80HTTPAccés web sense xifrar (opcional).
443HTTPSAccés web segur.

Marca Allow SSH, Allow HTTP i Allow HTTPS. Després prem Launch instance.

💡

Quan la instància estigui Running, copia'n la IP pública (Public IPv4 address). La faràs servir per connectar-t'hi i per obrir el web.

2.4 · Connectar-se per SSH

Obre un terminal a la teva màquina, a la carpeta on has desat la clau. Primer, protegeix la clau (SSH no accepta claus amb permisos oberts):

bash
chmod 400 aea2-key.pem

➜ Dona permisos restrictius a la clau. chmod 400 fa que només el propietari la pugui llegir; SSH no accepta claus amb permisos oberts.

Connecta't (substitueix IP-PUBLICA per la de la teva EC2). A les AMI d'Ubuntu l'usuari és ubuntu:

bash
ssh -i aea2-key.pem ubuntu@IP-PUBLICA

➜ Obre la sessió SSH a l'EC2. -i aea2-key.pem indica quina clau fer servir i ubuntu és l'usuari de les AMI d'Ubuntu.

Accepta la fingerprint el primer cop (yes). Quan hi entris, el prompt passarà a ser el de l'EC2: ja administres el servidor al núvol.

2.5 · Instal·lar Apache i activar HTTPS

Ja dins l'EC2 per SSH, instal·la Apache i activa SSL (igual que a l'A1.1):

bash — la teva màquina → EC2 (SSH)
sudo apt update

➜ Actualitza la llista de paquets disponibles.

bash — la teva màquina → EC2 (SSH)
sudo apt install apache2 -y

➜ Instal·la el servidor web Apache. -y accepta automàticament la instal·lació.

bash — la teva màquina → EC2 (SSH)
sudo a2enmod ssl

➜ Activa el mòdul ssl, que permet a Apache servir pàgines per HTTPS.

Genera el certificat autofirmat:

bash — la teva màquina → EC2 (SSH)
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout /etc/ssl/private/aea2.key \
  -out /etc/ssl/certs/aea2.crt

➜ Genera el certificat i la clau. És una sola ordre (les barres \ uneixen les línies): -x509 crea un certificat autofirmat, -nodes no posa contrasenya a la clau i -days 365 el fa vàlid un any.

En executar-la, l'openssl et farà unes quantes preguntes (el subject del certificat). Pots respondre-les així:

preguntes del certificat
Country Name (2 letter code):    # país, 2 lletres → ES
State or Province Name:          # província → Barcelona
Locality Name (eg, city):        # ciutat → Barcelona
Organization Name:               # organització → Institut La Merce
Organizational Unit Name:        # departament (opcional) → DAW
Common Name:                     # ⚠ EL MÉS IMPORTANT: l'adreça del servidor → IP-PUBLICA
Email Address:                   # correu (opcional) → pots deixar-ho buit
💡

El camp que de debò importa és el Common Name (CN): ha de coincidir amb l'adreça per la qual accediràs al servidor (aquí la IP-PUBLICA de l'EC2). La resta de camps són informatius i els pots deixar buits prement Enter.

Obre la configuració SSL per indicar-hi el certificat:

bash — la teva màquina → EC2 (SSH)
sudo nano /etc/apache2/sites-available/default-ssl.conf

➜ Obre el fitxer de configuració del lloc HTTPS.

Deixa les dues línies del certificat apuntant al teu:

default-ssl.conf
SSLCertificateFile      /etc/ssl/certs/aea2.crt
SSLCertificateKeyFile   /etc/ssl/private/aea2.key

Activa el lloc HTTPS i recarrega Apache:

bash — la teva màquina → EC2 (SSH)
sudo a2ensite default-ssl

➜ Activa el lloc HTTPS (default-ssl) a Apache.

bash — la teva màquina → EC2 (SSH)
sudo systemctl reload apache2

➜ Recarrega Apache perquè apliqui la nova configuració sense aturar el servei.

2.6 · Accedir al web des del navegador

Al navegador de la teva màquina, escriu la IP pública de l'EC2 amb https:

navegador
https://IP-PUBLICA

Accepta l'avís del certificat autofirmat i veuràs la pàgina d'Apache servida per HTTPS des del núvol.

3

Verificació

Des de la teva màquina, connectat per SSH a l'EC2:

bash — la teva màquina → EC2 (SSH)
systemctl status apache2
sudo ss -tlnp | grep -E ':(22|443)'

Sortida esperada de systemctl status apache2 (resumida):

sortida esperada
● apache2.service - The Apache HTTP Server
     Loaded: loaded (/lib/systemd/system/apache2.service; enabled; ...)
     Active: active (running) since ...   # ⚠ EL MÉS IMPORTANT
   Main PID: 1234 (apache2)
      Tasks: 55 (limit: ...)
     CGroup: /system.slice/apache2.service
             ├─1234 /usr/sbin/apache2 -k start
             ├─1235 /usr/sbin/apache2 -k start
             └─1236 /usr/sbin/apache2 -k start

Sortida esperada de ss -tlnp (una línia per port):

sortida esperada
LISTEN 0 128 0.0.0.0:22    0.0.0.0:*  users:(("sshd",pid=...,fd=3))     # port SSH
LISTEN 0 128 0.0.0.0:443   0.0.0.0:*  users:(("apache2",pid=1234,fd=6)) # port HTTPS

Des de la teva màquina:

bash
curl -k https://IP-PUBLICA

Sortida esperada (el codi HTML de la pàgina; el contingut exacte depèn del que hi hagis publicat):

sortida esperada
<html><body><h1>It works!</h1></body></html>
💡

L'opció -k fa que curl accepti el certificat autofirmat sense donar l'error SSL certificate problem. Si l'ordre respon amb HTML (sense error de connexió), la verificació és correcta.

  • La sessió SSH s'ha establert amb la clau .pem.
  • systemctl status apache2 mostra active (running).
  • curl -k retorna el codi HTML de la pàgina.
  • El navegador obre https://IP-PUBLICA correctament.
