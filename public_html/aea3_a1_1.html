Instal·la Tomcat i desplega una aplicació

Instal·laràs Tomcat a la màquina tomcat, l'obriràs des del client i hi desplegaràs la primera aplicació Java.

RA RA3 Màquina tomcat
0

Què faràs

  • Instal·lar Tomcat a la màquina tomcat.
  • Obrir Tomcat des del navegador del client.
  • Desplegar una aplicació Java (un fitxer .war).

Què necessites

  • Haver fet l'A1.0: les quatre màquines amb nom, IP fixa i SSH.
1

Què és Tomcat

Apache (AEA2) és un servidor web: envia fitxers que ja existeixen, com index.html.

Tomcat és un servidor d'aplicacions: executa programes Java i crea la pàgina en el moment. Les aplicacions es despleguen en un fitxer .war (un paquet amb tot el programa). Tomcat escolta al port 8080.

2

Pas a pas

💡

Cada pas ve dins d'una capsa de color que diu a quina màquina l'has de fer: ClientAdministradorApacheTomcatDiverses màquines.

2.1 · Entra a la màquina tomcat

Administrador
bash — admin
ssh isard@192.168.1.11

➜ Entra a la màquina tomcat per SSH amb l'usuari isard i la seva contrasenya. Quan el prompt digui isard@tomcat, ja hi ets.

2.2 · Instal·la Tomcat

Administrador → Tomcat · per SSH
bash — admin → tomcat (SSH)
sudo apt update
sudo apt install -y tomcat10

➜ Instal·la Tomcat 10. També instal·la Java automàticament, perquè Tomcat el necessita per funcionar.

bash — admin → tomcat (SSH)
systemctl status tomcat10

➜ Mostra l'estat de Tomcat. Ha de dir active (running). Prem q per sortir.

2.3 · Obre Tomcat des del client

Client
🔎 Comprova-ho al navegador del client http://192.168.1.11:8080

Ha de sortir la pàgina de Tomcat amb el missatge It works!

2.4 · Desplega una aplicació

Administrador → Tomcat · per SSH
bash — admin → tomcat (SSH)
cd /var/lib/tomcat10/webapps

➜ Entra a la carpeta webapps: tot el que hi posis, Tomcat ho publica.

bash — admin → tomcat (SSH)
sudo wget https://tomcat.apache.org/tomcat-10.1-doc/appdev/sample/sample.war

➜ Baixa una aplicació d'exemple, sample.war, directament a webapps.

bash — admin → tomcat (SSH)
ls

➜ Espera uns segons i torna-ho a mirar: al costat de sample.war apareixerà la carpeta sample. Vol dir que Tomcat ja l'ha desplegada.

Client
🔎 Comprova-ho al navegador del client http://192.168.1.11:8080/sample/

Ha de sortir la pàgina Sample "Hello, World" Application. Prova els enllaços JSP page i servlet: aquestes pàgines les crea el programa Java en el moment.

💡

Per retirar una aplicació, esborra el seu .war de webapps (sudo rm sample.war): Tomcat esborra la carpeta sola. No ho facis ara, que la farem servir a l'A1.2.

3

Comprova que ho tens tot

  • systemctl status tomcat10 diu active (running).
  • Des del client, http://192.168.1.11:8080 mostra It works!
  • Des del client, http://192.168.1.11:8080/sample/ mostra l'aplicació d'exemple.
4

Si alguna cosa falla

ProblemaSolució
apt diu Unable to locate package tomcat10Fes apt search tomcat i instal·la el paquet que surti (per exemple tomcat11). Llavors canvia 10 per 11 a totes les ordres.
El navegador no carrega :8080Comprova que Tomcat funciona (systemctl status tomcat10) i que has escrit la IP de tomcat (.11), no la d'apache.
/sample/ dona error 404Espera uns segons i mira amb ls si ja hi ha la carpeta sample. Si no hi és, mira l'error amb sudo journalctl -u tomcat10 -n 20.
