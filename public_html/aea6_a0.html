Primers passos amb Git i GitHub

Abans de treballar en parella, cadascú instal·larà les eines i practicarà tot sol amb un repositori d'usar i llençar. L'objectiu és agafar el ritme dels 4 comandaments bàsics de Git i veure l'historial de commits créixer.

Individual abans de l'A1 RA RA6 Repositori de pràctiques
0

Objectius i prerequisits

Aquesta activitat és individual: cadascú la fa sol, amb un repositori propi que no es farà servir més enllà d'aquesta pràctica. A l'A1 ja treballareu en parella amb el repositori "de veritat" de l'AEA6.

Prerequisits

  • Una màquina Debian amb connexió a Internet i permisos per instal·lar programes (sudo).
  • Un compte de correu electrònic per registrar-te a GitHub, si encara no en tens.
1

Context i teoria mínima

Què farem en aquesta activitat

Instal·larem l'editor de codi i Git al teu ordinador, crearem el teu compte de GitHub i l'autenticarem des del terminal. Després practicarem, amb un repositori d'usar i llençar, els 4 comandaments que faràs servir tota la resta del curs.

Termes nous que apareixeran:

  • Terminal: la finestra on escrius ordres de text en lloc de fer clic amb el ratolí. És l'eina principal per treballar amb Git.
  • Git: el programa que guarda l'historial de canvis del teu projecte, al teu ordinador (en local).
  • GitHub: el servei web que allotja una còpia central (remota) dels teus repositoris, perquè els puguis recuperar des de qualsevol ordinador o compartir-los amb altres persones.
  • GitHub CLI (gh): un programa que et permet fer accions de GitHub (com autenticar-te) directament des del terminal, sense haver de generar cap contrasenya especial a mà.
  • Repositori: la carpeta del teu projecte, amb tot el seu historial de canvis.

Els 4 comandaments bàsics

De totes les ordres que té Git, amb aquestes 4 ja pots treballar-hi el dia a dia. Les faràs servir constantment durant tot el curs:

ComandamentQuè fa
git add .Prepara els canvis (els posa "a la safata de sortida").
git commit -m "..."Guarda una foto del moment, amb un missatge que explica què has fet.
git pushPuja els teus commits a GitHub.
git pullBaixa a l'ordinador els canvis que hi hagi a GitHub (per exemple, els d'un company).
💡

Per connectar per primera vegada una carpeta del teu ordinador amb un repositori de GitHub, faràs servir un cinquè comandament, git clone, que descarrega tot el repositori. Un cop clonat, ja només et faran falta els 4 de la taula.

2

Pas a pas guiat

2.1 · Actualitzar la llista de programes

bash
sudo apt update

➜ Actualitza la llista de programes disponibles al sistema. Cal fer-ho abans d'instal·lar res de nou.

2.2 · Instal·lar Visual Studio Code

bash
sudo apt install wget gpg -y

➜ Instal·la dues eines petites (wget per descarregar fitxers, gpg per comprovar-ne l'origen) que calen per al pas següent.

bash
wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > packages.microsoft.gpg
sudo install -o root -g root -m 644 packages.microsoft.gpg /usr/share/keyrings/
rm packages.microsoft.gpg

➜ Descarrega la "signatura digital" de Microsoft i la desa al sistema. Serveix perquè Debian pugui comprovar que els programes que vindran d'aquest origen són autèntics.

bash
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/packages.microsoft.gpg] https://packages.microsoft.com/repos/code stable main" | sudo tee /etc/apt/sources.list.d/vscode.list > /dev/null

➜ Afegeix el "magatzem" (repositori) de Microsoft d'on Debian podrà descarregar VS Code.

bash
sudo apt update

➜ Torna a actualitzar la llista, ara que Debian ja coneix el magatzem nou.

bash
sudo apt install code -y

➜ Instal·la Visual Studio Code.

bash
code --version

➜ Comprova que s'ha instal·lat correctament: ha de mostrar un número de versió.

2.3 · Instal·lar Git i la GitHub CLI

bash
sudo apt install git gh -y

➜ Instal·la Git (el control de versions) i gh (la GitHub CLI, que farem servir al pas 2.6 per autenticar-nos sense complicacions).

bash
git --version
gh --version

➜ Comprova que tots dos s'han instal·lat correctament.

2.4 · Crear el compte de GitHub

Si encara no en tens un: ves a github.com/signup i registra't (correu, contrasenya i nom d'usuari; és gratuït).

2.5 · Configurar el teu nom i correu a Git

Git afegeix el teu nom i correu a cada commit. Es configura una sola vegada:

bash
git config --global user.name "El teu Nom"

➜ Guarda el teu nom. --global vol dir que val per a tots els projectes, no només un.

bash
git config --global user.email "el-teu-correu@exemple.com"

➜ Guarda el teu correu. Fes servir el mateix amb què t'has registrat a GitHub.

2.6 · Autenticar-te amb GitHub des del terminal

bash
gh auth login

➜ T'anirà fent preguntes; respon-les així:

  1. What account do you want to log into? → GitHub.com
  2. What is your preferred protocol for Git operations? → HTTPS
  3. Authenticate Git with your GitHub credentials? → Yes
  4. How would you like to authenticate? → Login with a web browser

Et sortirà un codi de 8 caràcters i s'obrirà (o t'oferirà obrir) una pàgina al navegador. Enganxa el codi, inicia sessió a GitHub si cal, i accepta l'autorització.

💡

Aquest pas és el que fa que git push i git pull funcionin sense demanar-te contrasenya cada vegada: gh guarda l'autenticació i Git la reutilitza automàticament.

2.7 · Crear el repositori de pràctiques a GitHub

  1. A github.com, fes clic al botó + (a dalt a la dreta) → New repository.
  2. Posa-li de nom practica-git.
  3. Deixa'l públic i marca l'opció Add a README file.
  4. Fes clic a Create repository.

2.8 · Obrir VS Code i clonar el repositori

  1. Obre VS Code.
⚠️

La primera vegada que s'obre VS Code, pot sortir una finestra que digui "Welcome to VS Code — Sign in to use GitHub Copilot". No té relació amb el que estem fent (Copilot és un assistent d'IA, no cal ara). Fes clic a Continue without Signing In (a baix a la dreta) per tancar-la.

  1. Crea (si no en tens ja) una carpeta per a la feina del curs, per exemple m0614 dins la teva carpeta personal. A VS Code, File → Open Folder… i selecciona-la (o crea-la des del mateix diàleg).
  2. Obre la terminal integrada amb Ctrl + J (o Terminal → New Terminal). S'obrirà ja situada dins la carpeta que acabes d'obrir.
💡

La terminal integrada és la mateixa que faries servir a part, però oberta dins l'editor: així pots escriure ordres i veure els fitxers alhora. La faràs servir a totes les activitats del curs.

A la pàgina del repositori a GitHub, fes clic al botó verd Code i copia la URL HTTPS. Després, a la terminal integrada:

bash
# Substitueix EL_TEU_USUARI pel teu nom d'usuari de GitHub
git clone https://github.com/EL_TEU_USUARI/practica-git.git

➜ Descarrega el repositori i crea, dins la carpeta que tenies oberta, una subcarpeta anomenada practica-git.

bash
cd practica-git

➜ Entra a la carpeta clonada. A partir d'ara, totes les ordres de Git d'aquesta activitat s'executen des d'aquí.

Finalment, obre aquesta carpeta a VS Code (File → Open Folder… → practica-git) perquè l'explorador de fitxers i la terminal apuntin al mateix lloc.

2.9 · Crear un fitxer i fer el primer commit

Ja amb la carpeta oberta a VS Code, crea un fitxer index.html amb el teu nom, per exemple:

index.html
<!DOCTYPE html>
<html lang="ca">
<body>
  <h1>Hola, sóc [El teu nom]</h1>
</body>
</html>

Desa el fitxer i, al terminal:

bash
git add .

➜ Prepara tots els fitxers nous o modificats (el punt . vol dir "tot el que hi ha en aquesta carpeta").

bash
git commit -m "Afegeix la meva pàgina inicial"

➜ Guarda la "foto" del moment, amb un missatge que explica què has fet.

bash
git push

➜ Puja el commit a GitHub. Recarrega la pàgina del repositori al navegador: hi hauria d'aparèixer el teu index.html.

2.10 · Simular el canvi d'un company (des de GitHub)

Ara faràs una modificació directament a la pàgina web de GitHub, sense passar pel teu ordinador. Serveix per simular que un company ha fet un canvi que tu encara no tens:

  1. Al repositori a GitHub, obre el fitxer index.html.
  2. Fes clic a la icona del llapis (Edit this file).
  3. Afegeix una línia, per exemple: <p>Aquest canvi ve de GitHub</p>.
  4. Baixa fins al final i fes clic a Commit changes... → Commit changes (deixant-ho pujar directament a main).

Aquest canvi ja existeix a GitHub, però encara no al teu ordinador. Comprova-ho obrint index.html a VS Code: la línia nova encara no hi surt.

bash
git pull

➜ Baixa els canvis fets a GitHub. Torna a mirar index.html a VS Code (si ja el tenies obert, es refrescarà sol): ara ja hi surt la línia que has afegit des del navegador.

2.11 · Fer un altre canvi i tornar a pujar-lo

Ara des del teu ordinador (a VS Code), afegeix una altra línia qualsevol a index.html, desa-la, i repeteix el cicle:

bash
git add .
bash
git commit -m "Segon canvi de prova"
bash
git push

➜ Ja portes 3 commits: el primer, el de GitHub (que has baixat amb pull), i aquest darrer.

3

Verificació

  • Al terminal, git log --oneline mostra els 3 commits, amb els missatges que has escrit tu i el que has fet des del navegador.
  • A github.com, al teu repositori practica-git, la pestanya de commits (número al costat de "Commits") mostra el mateix historial.
  • index.html conté les línies afegides des de l'ordinador i des del navegador, totes juntes.
💡
