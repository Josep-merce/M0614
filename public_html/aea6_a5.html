Disseny visual i documentació col·laborativa

Donareu estil a la vostra pàgina amb CSS i documentareu el resultat en una Wiki compartida, com a segona forma de documentació diferent de la web generada per JSDoc. Anirem pas a pas, amb exemples concrets de cada clic.

Repositori compartit RA RA6 CA 6.3 · 6.4 En parella Propietari · Col·laborador
0

Objectius i prerequisits

Continueu al mateix repositori compartit (aea6-usuari1-usuari2). A l'A4 vau generar una web de documentació amb JSDoc; ara documentareu el mateix projecte d'una manera diferent: donant-li estil visual amb CSS i explicant-ho en una Wiki, en lloc d'una web generada automàticament.

Prerequisits

  • Haver completat l'A1-A4: index.html amb header/footer, js/main.js, la carpeta docs/ generada amb JSDoc, i el README.md documentat en Markdown.
💡

Com sempre, main està protegida: tots els canvis d'aquesta activitat es faran a una branca nova, design/wiki, i es fusionaran amb un Pull Request al final.

1

Context i teoria mínima

Què farem en aquesta activitat

Donareu estil visual (colors, tipus de lletra, marges...) a la vostra pàgina web fent servir CSS, i documentareu el resultat a la Wiki del repositori amb una captura de pantalla i un fragment del codi. Serà una segona manera de documentar el projecte, diferent de la que vau fer amb JSDoc a l'A4.

Termes nous que apareixeran:

  • CSS (Cascading Style Sheets, "fulls d'estil en cascada"): un llenguatge que serveix per dir com s'ha de veure una pàgina HTML: colors, tipus de lletra, marges, mides, etc. Es guarda en un fitxer separat amb extensió .css i s'enllaça des de l'HTML.
  • Full d'estil: un fitxer .css amb regles d'aparença. Cada regla diu "tal element ha de ser així".
  • Wiki de GitHub: un conjunt de pàgines en Markdown, dins del mateix repositori, que qualsevol col·laborador pot crear o editar des del navegador. És diferent del README.md perquè permet tenir moltes pàgines organitzades.
  • Captura de pantalla: una foto de la pantalla del vostre ordinador. Al Linux es fa amb la tecla Print Screen (o ImprPant).
2

Pas a pas guiat

2.1 · Crear la branca de disseny

Propietari
bash
git checkout main
bash
git pull origin main
bash
git checkout -b design/wiki

➜ Les tres comandes de sempre: posar-te al dia amb main i crear una branca nova per a aquesta feina.

2.2 · Crear el full d'estil (CSS)

Propietari

Crea un fitxer nou anomenat style.css a l'arrel del projecte (al mateix nivell que index.html):

bash
nano style.css

Escriu-hi aquest contingut:

style.css
body {
  font-family: sans-serif;
  margin: 0;
  padding: 2rem;
  background: #F6F8FB;
  color: #1A2230;
}

➜ Aquest primer bloc afecta tota la pàgina (body): tipus de lletra, marges i colors de fons i de text.

Afegeix-hi a continuació aquest segon bloc:

style.css
header nav a {
  margin-right: 1rem;
  color: #E07B1E;
  text-decoration: none;
}

➜ Aquest bloc només afecta els enllaços (a) que estan dins d'un nav dins d'un header: els posa taronja, sense subratllat, amb espai entre ells.

I finalment aquest tercer bloc:

style.css
footer {
  margin-top: 2rem;
  padding-top: 1rem;
  border-top: 1px solid #ddd;
}

➜ Aquest bloc separa visualment el peu de pàgina (footer) amb una línia i una mica d'espai per sobre.

2.3 · Enllaçar el CSS des de l'index.html

Propietari

Obre index.html i afegeix aquesta línia dins de <head>, abans de </head>:

index.html
<link rel="stylesheet" href="style.css">

➜ Aquesta línia li diu al navegador: "abans de mostrar aquesta pàgina, aplica també els estils del fitxer style.css".

Obre index.html directament al navegador (sense necessitat de servidor) i comprova que s'ha aplicat el disseny: fons clar, enllaços taronja, línia sobre el peu.

2.4 · Pujar el CSS

Propietari
bash
git add style.css index.html
bash
git commit -m "Afegeix estils CSS a la pàgina"
bash
git push origin design/wiki

2.5 · Fer la captura de pantalla

Col·laborador

Primer, baixa't la branca amb el CSS ja aplicat:

bash
git fetch origin
bash
git checkout design/wiki

Obre index.html al navegador i fes una captura de pantalla de la finestra sencera. Desa-la al teu ordinador (per exemple, a l'Escriptori, amb el nom disseny.png).

2.6 · Crear la pàgina de la Wiki

⚠️

Una Wiki de GitHub és com un document de text amb format (Markdown): no pot executar CSS de veritat. Per això, en lloc de "publicar la pàgina en viu", hi posarem una foto de com queda i el codi que l'ha fet possible.

Propietari
  1. Ves al repositori a GitHub i fes clic a la pestanya Wiki (a dalt, al costat de "Pull requests").
  2. Fes clic al botó Create the first page.
  3. Deixa el títol per defecte: Home.
  4. Al camp gran de sota, escriu 2 o 3 frases explicant què és el projecte.
  5. Fes clic a Save Page.

2.7 · Afegir la captura i el codi CSS a la pàgina

Col·laborador

A la mateixa pàgina que ha creat el Propietari, fes clic a Edit (a dalt a la dreta). Al final del text que ja hi ha, deixa una línia en blanc i escriu:

camp de text de la Wiki
## Disseny visual

➜ El ## fa que es vegi com un subtítol dins de la pàgina.

Deixa una altra línia en blanc i, amb el ratolí, arrossega el fitxer disseny.png des de l'Escriptori cap a dins d'aquest mateix camp de text. Quan deixis anar el fitxer, GitHub hi escriurà automàticament una línia semblant a aquesta (no cal que la teclegis tu):

camp de text de la Wiki
![disseny](https://github.com/usuari1/aea6-usuari1-usuari2/assets/12345/abc-def.png)

Just a sota de la imatge, afegeix el codi CSS:

camp de text de la Wiki
```css
body {
  font-family: sans-serif;
}
```

➜ Les tres cometes inclinades ``` seguides de css li diuen a Markdown "el que ve ara és codi CSS, mostra-ho amb lletra de programació". Les tres cometes del final tanquen aquest bloc. No cal que hi posis tot el fitxer style.css, només un fragment representatiu com l'exemple.

Fes clic a Save Page.

Ambdós

5

Errors freqüents

ProblemaCausaSolució
La pàgina no mostra cap canvi de disseny La línia <link> no està dins de <head>, o el nom del fitxer no coincideix. Comprova que href="style.css" coincideix exactament amb el nom del fitxer creat.
La imatge no apareix a la Wiki El fitxer no s'ha arrossegat dins del camp de text, o encara s'estava pujant. Torna a arrossegar-lo i espera uns segons fins que GitHub inserti la línia ![...] automàticament.
El bloc de codi CSS es veu com a text normal, sense colors Falten les tres cometes inicials ```css o les finals ```. Comprova que hi ha exactament 3 cometes inclinades abans i després del codi.
El "Merge pull request" no es pot fer Encara no s'ha revisat el Pull Request, o hi ha un conflicte. Revisa els canvis a la pestanya "Files changed" abans de fer merge.
